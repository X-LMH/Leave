# App 首页

`GET /api/v1/home`，需要登录 Token，并沿用 App 版本校验请求头。
不接收学号、分页或筛选参数，始终返回当前登录账号的数据。

成功时沿用统一的 `code`、`message`、`data` 响应，`data` 示例：

```json
{
  "user": {
    "student_id": "20260001",
    "name": "张三",
    "classname": "计算机科学与技术1班",
    "avatar_url": "https://example.com/api/v1/uploads/avatars/student-a.png"
  },
  "statistics": {
    "total_count": 12,
    "month_count": 2
  },
  "latest_record": {
    "id": 123,
    "leave_type": "事假-本科生",
    "start_time": "2026-10-20T08:00:00+08:00",
    "end_time": "2026-10-20T11:00:00+08:00",
    "duration_days": 0,
    "duration_hours": 3,
    "is_leave_school": true
  }
}
```

## 统计口径

- 所有查询只包含当前账号的未删除假条。
- `total_count`：累计假条数量，包含已创建的未来请假记录。
- `month_count`：请假开始时间落在北京时间当前自然月的假条数量，含月初、不含下月月初。
- `latest_record`：按 `created_at DESC, id DESC` 取最新创建的一条；摘要使用假条保存的类型快照。
- `duration_days` 和 `duration_hours`：分别为完整天数和剩余小时。
- 统计和最新假条在同一个可重复读只读事务中查询；任一查询失败，整体返回现有服务繁忙错误。

无记录时两个统计字段均为 `0`，`latest_record` 为 `null`。
未登录沿用现有登录错误响应；不返回伪造的空统计掩盖数据库错误。

## 客户端

`utils/api.uts` 的 `getHome()` 解析响应。`HomeTabContent.uvue` 使用该接口替换原先的示例统计及“列表 + 详情”请求。
进入首页、切回首页或从其他页面返回首页时，优先复用当前会话内的 home 响应缓存；首页与“我的”并发读取时共用同一个请求。
新增或删除假条、保存资料、上传头像、登录或退出后清除 home 缓存，下次读取重新请求。重启应用后首次进入首页也重新请求。
过期请求和其他账号的响应不会覆盖当前缓存；失败不缓存，可重试。
加载或失败时统计显示占位符，失败可轻点重试，无假条时保留空态。
`user` 返回当前姓名和头像访问地址，头像地址沿用登录和资料接口的默认头像及存储地址规则；尚无资料时姓名为空，返回默认头像。
首页首先使用登录缓存展示姓名和头像，再通过 `/home` 更新；不再单独请求 `/profile`。
“我的”页优先使用当前账号缓存的学号、姓名、班级和头像，缓存字段缺失时才请求 `/home`，不再请求 `/profile`。
登录、首页请求、资料保存和头像上传沿用现有缓存更新流程；姓名或班级为空字符串是有效缓存，不因此重复请求。
`user.classname` 为当前班级名称，无班级时为空字符串。
`user.student_id` 来自当前登录身份，即使尚未填写个人资料也会返回学号。
个人资料查看及编辑页面继续使用资料接口，校园提醒继续使用固定文案。

## 验证

`go test ./...` 包含首页路由鉴权测试。`TestHomeIntegration` 需要显式设置 `MYSQL_TEST_DSN`，仅接受 loopback TCP MySQL，并创建、清理独立测试库，不读取业务库配置。
集成测试覆盖默认头像、姓名与自定义头像、空数据、账号隔离、软删除、北京时间跨年月份边界、最新假条时长取整、最新记录排序及删除后刷新；未配置 DSN 时跳过。
