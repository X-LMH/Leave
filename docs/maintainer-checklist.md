## 依赖与工作流维护

Dependabot 每周一北京时间 03:00 检查 Go、管理端 pnpm 和 GitHub Actions，各生态最多同时开启 3 个版本更新 PR；实际调度可能延迟。PR 需要人工检查变更与测试，不自动合并。Go 漏洞扫描使用相同周时段及 PR、手动触发，与部署独立。

所有外部 Action 固定完整提交 SHA，注释保留原版本。更新时核对上游仓库与标签；附注标签应解析到 commit，而不是把 tag 对象 SHA 当作 commit。固定 Action SHA 不等于固定其内部下载的全部依赖。

尚未包含在本轮的后续工程任务：全新环境启动实测与简化、最小开发数据初始化、完整 API 契约、管理端关键浏览器测试。它们需要各自的实现与验证，不应将已有说明视为已完成这些能力。
