# Android 发布验收清单

本清单用于人工记录验收，不代表已执行。部署与发布命令仍以 [部署说明](../deploy/README.md) 为准；运行本清单不自动授权访问服务器或发布。

## 验收记录

填写提交 SHA、`frontend/manifest.json` 版本名与版本号、HBuilderX 版本、设备型号与 Android 版本、目标环境、验收人及日期。只记录非敏感环境名称，不写凭据。每项记录通过、失败、跳过或阻塞，以及必要的脱敏证据。

## 编译与基础流程

- [ ] 使用 HBuilderX 完成 uni-app x Android 编译，确认无编译错误；Node 测试不代替此项。
- [ ] 在隔离测试环境确认 API、头像和上传 URL 可从设备访问；USB 调试按 README 配置 ADB 转发。
- [ ] 冷启动、登录、退出和重新登录正常；登录过期提示正确，服务暂时不可用时不误清除登录态。
- [ ] 资料读取、编辑、密码修改、头像选择与上传成功；拒绝权限、取消选择和上传失败均可恢复。
- [ ] 假条生成正常；空字段、起止时间和模拟通过时间的非法组合被拒绝；列表、详情、分页、删除及错误重试正常。
- [ ] 反馈文字与图片提交正常；使用虚构数据，不上传私人信息。
- [ ] 管理员入口与普通学生身份的可见性、权限提示正确；禁止把模拟时间字段视为真实审批结果。

## 外观与更新

- [ ] 浅色、深色、跟随系统的设置在冷启动和页面返回后保持一致，更新页也同步；检查键盘、滚动和返回导航。
- [ ] 当前版本无更新时提示正确；旧版本能获取新版本信息，更新说明顺序与分类正确。
- [ ] 下载进度、重复点击、断网、HTTP 失败、重试均正常；失败后可以再次下载。
- [ ] 安装授权拒绝后可重试；取消安装、已有 APK 重试和重新下载行为正常。
- [ ] 更新安装保留预期的资料与设置；版本名、版本号、APK 内容和发布配置一致。
- [ ] 校验发布 APK 的 SHA256 与 `SHA256SUMS`，检查 Release 下载链接与说明。

## 发布前结论

- [ ] 核对对应提交的后端和管理端 CI，单独确认 Go 漏洞扫描结果；检查失败、跳过和环境阻塞不得写成通过。
- [ ] 记录未通过项目及其影响；需修改或延期时在发布前处理，不将未验收版本标为已验证。
- [ ] 如需发布，由维护者按当前任务另行授权并执行现有发布流程；发布后确认目标版本和下载包，保留脱敏验收记录。
