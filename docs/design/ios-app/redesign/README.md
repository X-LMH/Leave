# 校园请假 · 完整 H5 交互预览

直接打开 `index.html`，无需安装依赖或连接后端。在 `docs/design/ios-app/` 目录运行 `python -m http.server 8766 --bind 127.0.0.1`，访问 `http://127.0.0.1:8766/redesign/`。静态服务仅共享预览目录。

## 页面与交互

登录与注册共用一个页面，通过分段控件切换；保留学号与密码输入，确认密码仅在注册时显示，退出注册模式时清空确认密码。页面只保留标题、切换、字段和提交按钮。

15 个预览入口：总览、登录、注册、记录、我的、个人信息、申请请假、编辑资料、完善资料、修改密码、用户反馈、显示与触感、关于应用、启动检查、版本更新。

桌面左侧、手机顶部的导航可选择页面；手机导航可横向滚动。请假申请为独立页面；完善资料与编辑资料也共用独立页面。URL 支持 `?page=home|login|register|records|profile|info|apply|edit|complete|password|feedback|appearance|about|launch|update`。

- 首页申请卡约 125px，最新假条约 175px，下方提供个人资料和填写提示。没有历史列表与统计卡，三个主页底色、加号位置与行为一致。
- 首页申请卡、填写提示和三个主页的加号均进入同一个独立申请页。返回、关闭、Escape 和预览导航离开时检查未提交修改，确认放弃后返回来源页；成功提交后进入记录并更新最新假条。
- 假条只有“已同意”状态；申请字段、长度、时长向上取整及地区联动沿用原 App。地区数据复用 `frontend/data/city.uts`，类型使用仓库初始化数据对应的演示选项。
- 注册成功进入独立的“完善资料”页，完成后进入首页。“我的 → 编辑资料”复用同一页面，保存后返回“我的”。两种场景共用字段、校验、班级和公寓演示选项，仅标题、说明和按钮文案不同；注册时清空个人资料，普通编辑载入已保存资料。
- 必填与手机号规则保持不变，公寓随性别切换，公寓与宿舍选填。姓名、头像保存后同步。返回、关闭、Escape 或预览导航离开时，未保存修改需确认；取消确认保留输入，放弃后返回来源页面（首次完善返回注册，普通编辑返回来源）。提交失败保留内容可重试。
- 资料页表单独立滚动，错误字段自动聚焦；焦点和视口缩小时滚动到当前字段，提交按钮在滚动内容内，保留底部安全间距。
- 改密包含旧密码、新密码、确认新密码和显隐；成功清空密码并返回登录，保留学号。不校验真实旧密码。
- 反馈支持 500 字、最多三张图片、预览和删除、匿名开关、提交结果。
- 显示设置实际控制动态效果、透明度和对比度；系统辅助设置仍生效。轻触反馈取决于浏览器与设备。
- 启动检查支持加载、失败重试与不同目的页；更新支持版本加载、进度、取消、下载失败和安装交接失败重试。

**假条详情除外**：当前仅提示后续按正式 App 的 1:1 样式复刻。正式 App 页面未修改。

## 演示场景与数据

展开 App 外的“演示场景”，可选择启动结果、下一次表单提交失败、版本加载、下载与安装交接结果，以及记录空列表、头像失败回退。

下一次提交失败会保留输入，再次提交即可成功，不需要离开当前表单。启动和版本失败场景需更换选择后重试。预览默认显示首页。

所有身份、版本、申请和结果均为虚构数据。数据、图片和偏好只在内存中，刷新重置；密码不持久保存，无浏览器存储和业务网络请求。图片使用本机 Blob URL。更新不下载 APK、不调用安装器，结果不代表服务器操作完成。
