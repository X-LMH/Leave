# Leave iOS 风格 H5 预览

直接用浏览器打开 `index.html`，无需安装依赖或连接后端。也可在本目录运行 `python -m http.server 8766 --bind 127.0.0.1`，打开 `http://127.0.0.1:8766/`。静态服务只共享此目录。

- 默认打开精修后的 B「轻盈玻璃」。左侧保留 A「原生简洁」对照，上方切换五个页面。方案切换保留页面、表单和滚动位置。
- 登录或注册输入符合格式的虚构学号及密码即可进入演示首页。不会向服务发送请求，也不写入浏览器存储。
- 支持 `?theme=glass&page=info`（主题：`native` / `glass`；页面：`login` / `register` / `home` / `profile` / `info`）。
- `?theme=native&overview=1` 和 `?theme=glass&overview=1` 是用于截图的五屏总览，普通预览入口支持完整交互。
- `overview-native.png`、`overview-glass.png` 是浏览器实际渲染的总览截图；`overview-glass-before.png` 保留精修前的 B 总览。
- `polished-home.png`、`polished-register.png`、`polished-info.png` 是精修后的 390px 手机页面截图。

仅用于视觉与基础交互评审，作为设计参考保存在 `docs/design/ios-app/`。身份数据均为虚构；本轮未更改 App 源码。H5 中的模糊材质和布局需要在后续 uni-app x 实现阶段分别验证 Android 兼容性。

## 精修版验证

2026-10-19，使用本机 Edge 无头浏览器实际渲染：

- 两套主题 × 五个页面 × 360 / 390 / 430px，共 30 组宽度检查，无横向溢出；所有按钮点击区域至少 44 × 44px。
- 学号、空密码、注册短密码及两次密码不一致的错误提示；有效登录和注册进入首页。
- 显示密码、切换风格保留输入、首页与我的切换、个人信息进入与返回、退出登录、未完成页面提示。
- 360px 下长班级名称自动换行，修改信息按钮可滚动到并点击；360 × 560px 下可操作退出、登录和返回，360 × 420px 下可滚动提交注册。
- 浏览器存储为空；减少动态效果时页面动画关闭；增强对比度时卡片为纯白且关闭背景模糊；错误字段聚焦时保留红边并显示焦点光圈；无 JavaScript 页面错误。
- B 文字色与背景色 token 的保守对比度计算：正文 10.14:1，辅助文字 5.00:1，占位文字 4.63:1，白色按钮文字 5.38:1。该计算针对主要文字，不涵盖装饰插画及 A 方案。
- 两张总览无纵向裁切，并人工查看总览及桌面截图。

不支持背景模糊及减少透明度的降级样式已提供；增强对比度已通过浏览器媒体模拟检查。短屏验证用于检查布局与滚动，未实测真实手机软键盘，未做 Android 真机或 HBuilderX 验证。
