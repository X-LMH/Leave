# 管理后台功能范围

## 业务约束

- 系统只保留一个管理员账号。
- 系统不包含请假审批功能，学生提交的内容直接形成请假记录。
- 后台主要用于查看、维护和统计数据。

## 功能范围

### 1. 管理员登录

- 管理员登录和退出登录
- 修改管理员密码
- 查看或修改管理员个人信息

### 2. 数据看板

- 学生数量
- 请假记录数量
- 各假期类型统计
- 最近提交的请假记录

### 3. 用户管理

- 查看学生列表
- 按学号、姓名、班级查询
- 查看和编辑学生资料
- 启用或禁用学生账号
- 重置学生密码
- 查看学生的请假记录

### 4. 请假记录管理

- 查看全部请假记录
- 按学号、姓名、班级、时间和假期类型筛选
- 查看请假详情
- 删除或作废错误记录
- 导出请假记录

### 5. 班级管理

- 新增、编辑班级
- 维护学院、专业和班级名称
- 启用或停用班级
- 查看班级学生

### 6. 假期类型管理

- 新增、编辑和删除假期类型
- 启用或停用假期类型
- 调整假期类型显示顺序

### 7. 公寓管理

- 新增、编辑公寓信息
- 区分男生和女生公寓
- 启用或停用公寓

### 8. 用户反馈管理

- 查看用户反馈
- 区分匿名反馈和实名反馈
- 删除反馈
- 标记反馈处理状态

### 9. 客户端版本管理

- 发布新版本
- 填写版本更新说明
- 查看历史版本
- 管理当前可用版本

## 推荐开发顺序

1. 管理员登录
2. 请假记录管理
3. 用户管理
4. 班级管理
5. 假期类型管理
6. 数据看板
7. 用户反馈管理
8. 公寓管理
9. 客户端版本管理
