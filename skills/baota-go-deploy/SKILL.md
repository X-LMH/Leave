# 宝塔 Go 项目切换与重启

用于准确切换宝塔面板中 Go 项目的执行文件，并重新启动指定项目。

## 执行前确认

- 确认宝塔 Go 项目的名称或编号。
- 只读检查该项目的启动脚本、执行文件路径、PID 文件、运行用户和日志路径。
- 不要根据项目名称猜测路径，也不要使用未确认的 `pkill`、`killall` 或停止全部 Go 进程的命令。

## 切换与重启流程

获得用户明确授权后，按以下顺序操作：

1. 将新的 Go 执行文件上传到服务器上的临时或版本目录。
2. 按宝塔启动脚本实际使用的路径替换项目执行文件。
3. 保留或恢复执行文件原有的属主、属组和可执行权限。
4. 从该项目专属 PID 文件读取 PID，只停止这个项目的旧进程。
5. 执行该项目对应的宝塔启动脚本，重新启动项目。
6. 只读验证目标进程、启动命令和项目日志。

## 宝塔项目脚本

如果宝塔 Go 项目存在类似以下启动脚本：

```sh
nohup /path/to/application &>> /path/to/project.log &
echo $! > /path/to/project.pid
```

必须替换 `/path/to/application` 指向的文件，然后停止 PID 文件记录的旧进程，最后重新执行该启动脚本。不要只在其他目录上传文件后直接启动，因为宝塔项目仍会执行原路径的旧文件。

## 安全边界

只读取服务器信息时，不得修改任何文件或进程。执行文件替换、停止进程和重启项目都必须有用户明确授权。操作范围仅限用户指定的宝塔 Go 项目及其已确认的相关路径，不执行其他服务器维护、升级、清理或防火墙操作。
